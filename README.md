# Password Validator

Программа проверяет надёжность пароля по набору правил и выводит результат.

## Правила проверки

Пароль считается надёжным, если:
1. Длина не меньше 8 символов
2. Есть хотя бы одна заглавная латинская буква (A–Z)
3. Есть хотя бы одна строчная латинская буква (a–z)
4. Есть хотя бы одна цифра (0–9)
5. Есть хотя бы один специальный символ: ! @ # $ %
6. Нет пробелов

## Формат вывода

- Если пароль надёжный → `OK`
- Если нет → `FAIL` и список нарушений:
  - `LEN` — длина меньше 8
  - `UPPER` — нет заглавной
  - `LOWER` — нет строчной
  - `DIGIT` — нет цифры
  - `SPECIAL` — нет спецсимвола
  - `SPACE` — есть пробел
## Примеры

Ввод: abc
Вывод: FAIL LEN UPPER DIGIT SPECIAL

Ввод: abc123
Вывод: FAIL LEN UPPER SPECIAL

Ввод: ABCabc123@
Вывод: OK

## Как это работает

1. Программа читает пароль.
2. Проходит циклом по каждому символу.
3. Для каждого символа проверяет: заглавная? строчная? цифра? спецсимвол? пробел?
4. Результат каждой проверки запоминает в отдельной переменной.
5. После цикла проверяет все условия и выводит OK или FAIL с кодами нарушений.
